# Amyloid Explorer — analysis code

This repository contains the analysis code and processed data that reproduce the
figures and statistical results in:

> Kyriazis *et al.*, "Amyloid Explorer: a standardized framework for comparative
> analysis of amyloid fibril structures and thermodynamic annotation",
> *Nature Communications* (2026).

The interactive **Amyloid Explorer** platform and the full structural database
are freely available at **https://amyloid-explorer.switchlab.org**. The automated
pipeline that ingests, standardises and thermodynamically annotates deposited
fibril structures is described in the paper's Methods; this repository provides
the downstream analysis that turns the annotated data into the paper's figures.

## Contents

- `code/` — R scripts that generate each figure and the statistical analyses.
- `data/` — the processed data the scripts consume.
- `output/` — figures are written here (per-panel PDFs), created on first run.

## Reproducing the figures

**Requirements:** R (≥ 4.3) with `dplyr`, `tidyr`, `readr`, `stringr`, `tibble`,
`ggplot2`, `patchwork`, `ggrepel`, `lmerTest`, `emmeans`, `lme4`. Figures render
through `cairo_pdf`; on macOS this needs XQuartz, and R should run in a UTF-8
locale (e.g. `LANG=en_US.UTF-8`) so Greek/maths glyphs (Δ, α, ρ, ≤) render.

From the `code/` directory:

```sh
Rscript Fig1.R             # Figure 1  — dataset composition
Rscript Fig3.R             # Figure 3  — residue-level grammar & segmental architecture
Rscript Fig4.R             # Figure 4  — functional vs pathological architecture & surface
Rscript Fig5.R             # Figure 5  — sample-origin effects (pathological subset)
Rscript Fig6.R             # Figure 6  — energetic context of disease mutations
Rscript SuppFig1.R         # Supplementary Fig. 1 — robustness with tau + α-synuclein excluded
Rscript SuppFig2.R         # Supplementary Fig. 2 — ΔG vs resolution and vs Cα B-factor
Rscript SuppFig4.R         # Supplementary Fig. 4 — surface-composition control
Rscript robustness_audit.R # protein-level bootstrap of every reported effect
```

Each script writes per-panel PDFs to `output/`. `load_energies.R` (data loader)
and `utils.R` (shared palette/theme) are sourced by the figure scripts.

> Figure 2 is a screenshot of the web interface, and the Landscape Explorer
> network figures (Fig. 7 and related supplementary panels) are produced by the
> interactive platform; neither is reproduced here.

## Data (`data/`)

| file | contents |
|---|---|
| `Final_Structs_AE_energies.csv` | per-residue FoldX ΔG profiles (sliding-window and per-residue, per stack) |
| `amyloid_explorer_db.tsv` | curated structure metadata (protein, role, sample origin, technique, resolution, mutations) |
| `amyloid_surface_composition_per_residue.tsv` | per-residue solvent exposure in the normalised fibril stack |
| `bfactors_per_residue.tsv` | per-residue Cα B-factors |
| `physprops.txt` | AAindex physicochemical scales |
| `*_scales_mw_results.tsv`, `robustness_audit.tsv` | precomputed statistics (also regenerated by the scripts) |
